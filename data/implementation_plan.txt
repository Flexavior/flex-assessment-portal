1. PROJECT OVERVIEW
================================================================================

This system automates the grading of student assignment submissions using
AI/LLM with RAG (Retrieval-Augmented Generation). It:
- Accepts student report files uploaded into data/students/
- Uses baseline course materials (slides, textbook) and rubric as reference
- Uses the assignment questions to check what the student was ASKED to answer
- Scores the student against the rubric using an LLM (Ollama + qwen)
- Generates PDF reports in data/reports/ as {student_name}_{date}.pdf

The system is lightweight, portable, and can eventually be accessed via a
simple HTML/CSS/JavaScript webpage for file upload.

5. TECHNICAL NOTES & CONSTRAINTS
================================================================================

Hardware: GPU with 6GB VRAM (e.g., RTX 1660 Ti)
- MAX_CHARS_PER_ANSWER = 5000 to prevent OOM
- GC collect + time.sleep(2) between students to free VRAM
- TOP_K = 3 for retrieval context

LLM: Ollama
- Model: qwen3.5:9b (fallback: qwen2.5:7b)
- URL: http://localhost:11434
- Embedding: nomic-embed-text
- Temperature: 0.1 (deterministic for grading)

Vector Store: llama_index local (ChromaDB/FAISS on disk)
- Built ONCE for static course materials
- Located at data/index/
- To rebuild: delete data/index/, restart

File Parsing: app/ingestion.py
- PDF: pdfplumber
- DOCX: python-docx
- PPTX: python-pptx
- Plain TXT: built-in
